5 · Rotate DEK (revoke & re-encrypt)

Re-encrypts every database under a fresh key and issues a NEW envelope + recovery code, orphaning every other method. This is how you evict a lost/compromised device. Limit: it protects future state and forces an attacker off the live DB — it cannot un-leak data already exfiltrated, nor re-encrypt old exported copies they kept.

6 · Portability & self-custody

Recover a downloaded bundle with the standalone tool (no Freehold runtime):

cargo run -p freehold-decrypt --release -- vault.freehold "YOUR-RECOVERY-CODE" ./out
# → ./out/app.sqlite  (open with any sqlite3)
